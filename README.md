# 📝 AcNotes - Modern Offline-First Android Notes

تطبيق أندرويد عصري وفائق السرعة للملاحظات والتدوين:
- **Offline-First:** يعمل بالكامل دون الحاجة لأي اتصال بالإنترنت باستخدام IndexedDB.
- **Cloud Sync:** مزامنة سحابية هادئة وفورية مع Cloudflare R2 عند توفر الإنترنت.
- **RTL & LTR Support:** دعم كامل للغة العربية والإنجليزية والتنسيق المختلط.
- **Markdown & KaTeX:** دعم كامل لتنسيق الماركداون، القوائم التفاعلية، والمعادلات الرياضية.
- **Fast & Lightweight:** واجهة ناعمة وتصميم عصري بالوضع الداكن.
