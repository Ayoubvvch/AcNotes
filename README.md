# 📝 AcNotes - Modern Offline-First Android Notes

تطبيق أندرويد نقي، فائق السرعة، ومصمم خصيصاً للملاحظات والتدوين الاحترافي:
- **Offline-First & Lightning Fast:** أداء نقي وفوري بالكامل محلياً عبر SQLite مع وصول فوري للملاحظات في أجزاء من الثانية.
- **True Full-Text Search:** بحث فوري وشامل في العناوين، المجلدات، ونصوص الملاحظات بالكامل.
- **Smart Writing Engine:** محرر ماركداون متقدم مع إكمال تلقائي ذكي للقوائم والمهام عند الضغط على Enter، إدراج ذكي للعناوين، شريط أدوات سريع، وحفظ تلقائي للملاحظات.
- **Math & Markdown Reader:** دعم فائق لمعادلات LaTeX عبر KaTeX، جداول، أكواد برمجية، وقوائم مهام تفاعلية متزامنة فوراً.
- **Cloudflare R2 Cloud Sync:** مزامنة سحابية هادئة وفورية تدعم الـ Pagination لمعالجة آلاف الملاحظات دون استهلاك بطارية أو فقدان بيانات.
- **RTL & LTR Support:** دعم نقي ومتكامل للغة العربية والإنجليزية والتنسيق المختلط مع خطوط مريحة للعين في الوضع الداكن.
